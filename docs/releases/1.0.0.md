# Matrix Studio 1.0.0 for Linux

Configure one or two Framework Laptop 16 LED Matrix panels from the desktop.
Assign each panel a clock, battery gauge, or assistant reading. Preview a draft
on the hardware for ten seconds before saving it. Closing the window leaves
the independent user daemon running.

- Optional OpenAI subscription usage and OpenCode session activity have been
  exercised on Linux. Claude usage and helper integration have fixture coverage
  only. Neither integration is required to use the panels.
- Arch/CachyOS x86-64 is the package target. Two-panel hardware evidence is
  from CachyOS with Hyprland. Windows is not supported in this release.
- Live module removal interrupted keyboard/touchpad input in testing. Do not
  remove modules to troubleshoot. An intermittent serial write failure remains
  unexplained; hot-swap recovery is not qualified.

For installation and upgrades, see the [package guide](https://github.com/jschraub/fw16-ledmatrix/blob/v1.0.0/docs/PACKAGING.md).
If migrating from the Python prototype, [stop the old writer first](https://github.com/jschraub/fw16-ledmatrix/blob/v1.0.0/docs/MIGRATION.md).
The [wiki](https://github.com/jschraub/fw16-ledmatrix/wiki) has first-run instructions.
