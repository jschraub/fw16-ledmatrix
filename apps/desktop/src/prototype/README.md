# Matrix Studio — interaction studies for #41

From the checkout: `npm run design --prefix apps/desktop`. The bottom arrows
compare three concepts on the same route. Copy the URL to share the selected
concept. State lives in memory and survives theme switches; reload resets it.

## Design brief

The everyday job is “put something useful in that bay and make it comfortable
to look at.” The previous panel map made the edit findable, but the owner found
the experience cluttered and disliked its appearance. This study tests what the
user wants to choose **first**. The alternatives can be combined:

| First decision | Primary surface | Visual language |
| --- | --- | --- |
| Which physical panel? | A · Signal room: two illuminated objects, each an edit target | Near-black green, round phosphor dots, generous dark space |
| What information? | B · Field notes: content index with a target side | Warm paper, editorial type, indexed figures |
| Which output needs adjustment? | C · Operator: channel selector and one large readout | Charcoal instrument face, amber light, monospace numerals |

Labels sit beside what they describe. Whitespace separates decisions; borders
mark shared objects rather than boxing every control. Ordinary text stays
proportional and legible. The Matrix reference is confined to vertical light
and phosphor, not decorative code rain. Toggle square LEDs to compare directly.

In all three studies, editing has one screen: preview, content, brightness,
then save or discard. Only the preview responds while editing. If carried into
the product, first launch should offer assignment in place of an empty bay;
loss of connection should replace live output with a reconnect action while
preserving drafts. Integrations, discovery and diagnostics belong at the point
of need or under settings. These service states are not simulated here.

**Review task:** Make the right panel show weekly usage, dim it, then decide
whether to keep the result. Which starting point felt natural? Which theme
would you want to see every day? Owner verdict pending.
